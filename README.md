## This site

The studio website is a single static page: plain HTML, CSS and JavaScript, with no framework and no build step. It is hosted on GitHub Pages.

- **Bilingual:** Spanish and English, following the visitor's browser language.
- **Accessible:** keyboard navigation, a skip link, and respect for `prefers-reduced-motion`.
- **Discoverable:** Open Graph and Twitter Card metadata, plus Schema.org structured data.

To run it locally:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>.
